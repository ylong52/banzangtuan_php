# 商品查询功能说明

## 功能概述

本功能提供了京东商品查询功能，包括：

1. **商品链接输入**：支持输入京东商品链接或关键词
2. **商品信息查询**：通过AJAX实时查询商品信息（名称、价格、优惠券等）

## 使用方法

### 1. 访问功能页面

在后台管理系统中，可以通过以下URL访问：

- 主功能页面：`/admin/jdgoods/query`

### 2. 查询商品信息

1. 在文本框中输入京东商品链接或关键词
2. 点击"查询商品"按钮
3. 系统会显示商品详细信息，包括：
   - 商品名称
   - 现价和原价
   - 优惠券信息
   - 店铺名称

## 技术实现

### 后端文件

- **控制器**：`app/Admin/Controllers/JdGoodsController.php`
  - `goodsQueryPage()`: 显示查询页面
  - `queryGoods()`: 处理AJAX商品查询请求

- **服务类**：`app/Services/JdGoodsSevice.php`
  - 处理京东API调用
  - 解析商品信息

### 前端文件

- **视图文件**：`resources/views/admin/jd_goods/query.blade.php`
  - 包含输入框、按钮和显示区域
  - 使用jQuery处理AJAX请求

### 路由配置

在 `app/Admin/routes.php` 中添加了以下路由：

```php
$router->get('jdgoods/query', 'JdGoodsController@goodsQueryPage')->name('jd_goods.query_page');
$router->post('jdgoods/query', 'JdGoodsController@queryGoods')->name('jd_goods.query');
```

## 功能特点

1. **实时查询**：使用AJAX技术，无需刷新页面即可查询商品信息
2. **智能解析**：自动从京东链接中提取商品信息
3. **简洁界面**：只保留核心查询功能，界面简洁易用
4. **错误处理**：完善的错误提示和异常处理机制

## 注意事项

1. 确保京东API配置正确（appkey和appSecret）
2. 网络连接正常，能够访问京东API
3. 输入的链接格式需要符合京东商品链接规范
