# 商品保存功能说明

## 功能概述
在京东商品查询页面中，新增了保存商品信息和分享文案的功能。用户可以在查询商品后，输入分享文案并保存到数据库中。

## 使用方法

### 1. 查询商品
- 在商品查询页面输入商品链接或关键词
- 点击"查询商品"按钮
- 系统会显示商品详情信息

### 2. 输入分享文案
- 商品查询成功后，页面会显示"分享文案"区域
- 在文本框中输入商品分享文案
- 支持使用商品信息变量

### 3. 保存商品信息
- 点击"保存商品信息"按钮
- 系统会将商品信息和分享文案保存到数据库
- 保存成功后会显示成功提示并清空文案

## 技术实现

### 后端
- **控制器**: `app/Admin/Controllers/JdGoodsController.php`
- **方法**: `save()` - 处理保存请求
- **路由**: `POST /admin/jdgoods/save`

### 前端
- **页面**: `resources/views/admin/jd_goods/query.blade.php`
- **JavaScript**: 保存按钮点击事件处理
- **AJAX**: 发送保存请求到后端

### 数据库
- **模型**: `app/Models/Goods.php`
- **字段**: `share_copywriting` - 存储分享文案

## 数据流程

1. 用户查询商品 → 获取商品信息
2. 输入分享文案 → 前端验证
3. 点击保存按钮 → 发送AJAX请求
4. 后端处理 → 保存到数据库
5. 返回结果 → 前端显示提示

## 错误处理

- 商品信息为空时显示错误提示
- 分享文案为空时显示错误提示
- 网络错误时显示友好提示
- 保存失败时显示具体错误信息

## 注意事项

- 必须先查询商品信息才能保存
- 分享文案不能为空
- 相同商品会更新现有记录
- 保存成功后会自动清空文案内容
