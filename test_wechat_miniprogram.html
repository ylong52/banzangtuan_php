微信小程序手机号获取测试

⚠️ 重要说明

这个页面用于测试微信小程序手机号获取功能。在实际使用中，你需要：

  1. 在微信开发者工具中创建小程序项目
  2. 使用真实的微信 AppID 和 AppSecret
  3. 通过 wx.getPhoneNumber() 获取手机号
  4. 将获取到的数据发送到后端接口

📱 微信小程序端代码示例

// 获取手机号 wx.getPhoneNumber({ success: (res) => { console.log('获取手机号成功:', res); // 发送到后端 wx.request({ url: 'YOUR_API_URL', method: 'POST', data: { detail: res, openid: 'user_openid', invitationCode: '1234' // 可选 }, success: (response) => { if (response.data.status === 'success') { // 保存 token wx.setStorageSync('token', response.data.data.token); // 保存用户信息 wx.setStorageSync('userInfo', response.data.data.user); } } }); }, fail: (err) => { console.error('获取手机号失败:', err); } });

🔧 调试步骤

  1. 确保后端服务正在运行
  2. 检查微信配置文件 config/wechat.php
  3. 确认 AppID 和 AppSecret 正确
  4. 使用真实的微信 code（从微信开发者工具获取）
  5. 检查网络连接和防火墙设置
  6. 查看后端日志文件
